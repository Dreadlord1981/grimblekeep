# Art direction reference

`approved-3d-direction.png` is the concept generated in the project conversation
on 2026-11-12 with OpenAI's built-in image-generation tool. The user approved this
direction: expressive imps, perspective depth, a dirty torch-lit dungeon and subtle
desktop HUD. Generated source: `exec-f0b0b7df-675d-43d2-8d42-3c0f767be7cc.png`.

It is visual reference only, not a screenshot of the implemented game or a usable
3D asset. Its grey resource icon is superseded: only gold/food are economic
resources. Subsequent user approval permits simpler retro low-poly graphics for
the first playable version. Current runtime assets are original procedural meshes
and materials made in `presentation/` and the drawn hand in `ui/keeper_hand.gd`.
